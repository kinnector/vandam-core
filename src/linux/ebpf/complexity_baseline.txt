# vandam-core BPF verifier complexity baseline
#
# Regenerate with:
#   sudo ./build/bin/kinnector-bpf-complexity measure build/kinnector.bpf.o \
#       --out src/linux/ebpf/complexity_baseline.txt
# WARNING: --out rewrites this whole file, including these notes. To add a new
# program, measure without --out and add its line by hand. Regenerate only when
# the reference kernel moves, then restore the notes.
# Check against it with:
#   ./scripts/check-bpf-complexity.sh
#
# Counts are the verifier's own "processed N insns", measured per program with
# every other program's autoload turned off. The ceiling is 1000000; the tool
# fails a program at 75% of it.
#
# These numbers are KERNEL-DEPENDENT - a different kernel's verifier explores a
# different number of states for identical bytecode. Treat a diff taken across
# two different kernels as noise, and regenerate the baseline when the
# reference kernel moves. Recorded on 6.17.0-40-generic.
#
# HOW KERNEL-DEPENDENT, measured on identical bytecode. The worst program
# (tracepoint_sys_enter_execve/execveat, and the totals track it):
#
#   6.1.186    509740 insns   51.0% of ceiling    total 1108017
#   6.6.155    509730 insns   51.0% of ceiling    total 1082326
#   6.12.107   205961 insns   20.6% of ceiling    total  483267
#   6.17.0     205857 insns   20.6% of ceiling    total  488660
#   6.18.46    205857 insns   20.6% of ceiling    total  488833
#
# So the same object costs 2.47x more verifier work on 6.1/6.6 than on 6.12+,
# and that ratio is almost entirely those two tracepoints (every other program
# moves by <10%). The cliff sits between 6.6 and 6.12.
#
# Why this matters for the gate: it fails a program at 75% of the ceiling. Read
# on a 6.12+ host the worst program looks like it has 79% headroom; on 6.1 and
# 6.6 - Debian 12 and the 6.6 LTS line, real deployment targets - it has 49%.
# A change that adds ~47% to that program passes there and is rejected outright
# on the older kernels, which is the -E2BIG-and-enforce-nothing failure this
# gate exists to catch. Re-measure on 6.1 (in a VM) before assuming headroom.
#
